Cara Deploy Gratis ke Vercel

  1. Simpan kode aplikasi ini dengan nama index.html.
  2. Buat repositori baru di GitHub dan unggah file tersebut.
  3. Buka Vercel.com, daftar/login menggunakan akun GitHub Anda.
  4. Klik Add New... > Project, lalu pilih repositori GitHub Anda.
  5. Klik Deploy tanpa mengubah pengaturan apapun. Vercel akan memberikan domain gratis secara instan!
